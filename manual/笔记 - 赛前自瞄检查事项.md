笔记：赛前自瞄检查事项 {#note_2}
===============

### 一、赛前自瞄检查
&emsp;&emsp;在完成所有工作、可以准备上场后，我们需要在上场前对自瞄做好详细的检查，~~不然上场发现颜色调错了或是其他低级错误导致的掉自瞄会很红温的（悲）~~。
&emsp;&emsp;保险起见，需要在调试场地、备场区都进行一次检查。
#### (1) 直接检查功能：
- 首先，打开NUC(新串有开机时NUC自启，老串需要主动按电源键打开)，无需接入电脑，直接拿装甲板照片在相机前面晃，看看头有没有跟上。
   - **照片不要拿的太近了** ，相机画面很小的，太近又晃的太快会导致识别不出来哦。
- 然后打开NUC，在debug模式里强制发送大符指令后再打开自瞄，检查能否正常识别大符。
#### (2) 校对参数：
之后就是校对一下参数了，包括以下内容：
1. **打符是否是手动的** ？这个是在src里面调的！之后考虑把它写到参数里。
2. **打符的模型** 对吗？
3. **颜色** （在之前的直接检查中就能看出来）。
4. **曝光** 对吗？
5. **内录** recorder开了没有？
6. 参数文件中的 **各种bool变量** 是否正确，如泼水等。
7. 检查相机接口是否变化（机械可能不知道要插哪个，拆装车的时候可能会变），不知道对不对可以打开自瞄然后手动云台，观察红框是否能够快速到达。

### 二、赛后内录检查
内录是直接录制NUC收到的画面得到的视频，在赛后检查中非常有用。
#### (1) 修复内录
&emsp;&emsp;比赛中，有可能因为车之间的撞击等原因，NUC可能会断电，这会导致内录直接中断，无法正确记录视频的结束时间。我们可以利用ffmpeg重新封装视频来修复：
```
ffmpeg -i 损坏的视频.avi -c copy 修复后的视频.avi
```
#### (2) 剪辑打符画面
&emsp;&emsp;我们需要使用打符的画面来训练识别模型，因此需要将内录中有能量机关的画面剪辑出来，可以使用ffmpeg来剪辑视频。（以下的`00:00:00`分别对应视频的时、分、秒）。
```
ffmpeg -i 比赛内录.avi -ss 00:00:00 -to 00:03:22 -c copy 比赛内录_能量机关.avi
```
#### (3) 检查掉自瞄原因
&emsp;&emsp;赛场上车掉自瞄是很常见的问题，我们需要通过<span style="color: #FF0000"><b>回看内录和日志来查找问题。</b></span>

&emsp;&emsp;这里非常建议记录 **比赛开始和结束的大致时间点** 。这是因为不论是内录还是B站上的回放都不会标出当前时间，而日志中每条记录却会标出当前时间。

&emsp;&emsp;我们可以 利用记录的比赛时间点 结合异常的日志快速找到是 **比赛的第几分钟出现了问题** ，从而更快的找到掉自瞄的录像以发现问题。
